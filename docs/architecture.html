What the shape guarantees

  • Postgres is truthFlush Redis and every link still resolves.
  • Collision-checkedPrimary key plus retry; a duplicate never overwrites a live code.
  • Revocation is immediateDelete evicts the cache entry in the same request.
  • Redirects never waitClicks go through a bounded buffer, not a synchronous insert.
  • Instances share nothingNo sessions or in-process counters, so the balancer needs no affinity.
  • Degrades, not failsCache and limiter fail open; only Postgres is required for readiness.

Codes: 7 base62 chars from crypto/rand, ~3.5 × 1012 values, unique by primary key.
