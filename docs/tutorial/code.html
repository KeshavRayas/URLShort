Before you copy it

Deterministic, never checked

Same url + user always yields the same code, and nothing tests whether that 8-char slice already belongs to another URL.

Every link dies in 6 hours

The cache TTL is the only TTL. When it lapses the next visit panics into a 500 instead of a 404.

user_id salts the hash, then vanishes

It is never persisted, so a user’s links can’t be listed, counted or revoked.

Worth keeping

A pure, testable generator behind one narrow store interface — and Base58 picked for humans, not machines.
